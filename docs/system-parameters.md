# System Parameters

The project studies a high-capacity DWDM optical communication system in
OptiSystem.

| Parameter | Description |
|---|---|
| Simulation platform | OptiSystem |
| System type | Dense Wavelength Division Multiplexing (DWDM) |
| Target capacity | Up to 2.4 Tbps |
| Maximum channel count studied | 128 |
| Fiber | Single-Mode Fiber (SMF) |
| Dispersion compensation | Dispersion Compensating Fiber (DCF) |
| Amplification | Optical Inline Amplifier |
| Main metrics | BER, Q-factor, optical spectrum, eye diagram |

The numerical values shown in the result files should be interpreted together
with the corresponding simulation configuration.

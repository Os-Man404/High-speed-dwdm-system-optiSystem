# High-Speed DWDM System Simulation Using OptiSystem

This repository documents a group project focused on the design and simulation
of a high-capacity Dense Wavelength Division Multiplexing (DWDM) system using
OptiSystem.

The work explores optical inline amplification, dispersion compensation, and
channel scalability for a target configuration of up to 2.4 Tbps. The
repository contains system designs, simulation outputs, graphs, and supporting
technical notes.

## Main Topics

- DWDM system design
- Optical Inline Amplifier (OA)
- Dispersion Compensating Fiber (DCF)
- Single-Mode Fiber (SMF)
- BER and Q-factor analysis
- Optical spectrum analysis
- Eye-diagram inspection
- Channel scalability analysis

## Repository Structure

